# Archtale

Модель архитектуры живёт блоками `model` в этой документации, схемы draw.io генерируются из неё.

````md
```model order-flow
customer "Покупатель" [person] -> site "Сайт" [application]: заказ
site -flows-> bank: оплата
```

<!-- archtale:diagram order-flow -->
````

- Строка блока: `[id-связи] откуда -тип-> куда: подпись`; обязательны только `откуда -> куда`. `#` — комментарий.
- Элемент: `id "Имя" [тип]`. Един на всю документацию, имя и тип достаточно указать один раз. Id и типы в kebab-case.
- Блоки с одним id собираются из всех файлов в `diagrams/<id>.drawio.svg` в корне. Блоки без id — схема своего файла в `diagrams/` рядом с ним.
- Блок без связей только объявляет элементы и схемы не создаёт.
- Тег `<!-- archtale:diagram [id] -->` подключает схему: генератор ставит картинку под ним.
- `archtale-types/<тип>.drawio.svg` — фигура типа, подстановки `%caption%`, `%id%`, `%type%`.
- Меняй модель в блоках, а не в схеме: подписи и связи берутся из модели. На схеме правят только раскладку.
- Команды из корня документации: `archtale generate`, `archtale check`.
