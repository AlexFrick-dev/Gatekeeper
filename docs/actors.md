# Действующие лица

Где-то внизу, в преисподней цеха, живут бесы: ПЛК, модули ввода-вывода, датчики. Говорят они на древних наречиях и чужих не слушают. Чернокнижникам наверху нужна их сила, но прямой путь вниз опасен. Поэтому у врат стоит привратник: он знает свитки с именами бесов, открывает врата и решает, кому что позволено. 
Достаточно лирики, дальше в документации только техника.

**Gatekeeper** — шлюз между OPC UA-клиентами и полевыми устройствами.

```model
gatekeeper "Gatekeeper" [gk]
```

**Warlock** — OPC UA-клиент: приложение, которое читает теги. Например, SCADA, MES, HMI.

```model
warlock "Warlock" [warlock]
```

**Scroll** — файл конфигурации. Задаёт адреса в поле и пространство имён OPC UA.

```model
plc-config "Scroll для ПЛК" [scr]
```

**Gate** — драйвер протокола, через который Gatekeeper обращается к устройству. Например, Modbus TCP.

```model
modbus-tcp "Modbus TCP" [gate]
```

**Imp** — любое полевое устройство: ПЛК, модуль ввода-вывода, АЦП.

```model
plc "ПЛК" [imp]
```
